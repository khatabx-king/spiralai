# SpiralAI 🌀

**A physics-verified AI agent for exploring graphene mechanical energy-storage concepts with Meta Muse Spark Open.**

> **Muse designs. Physics calculates. The verifier decides.**

SpiralAI explores a scientific question:

> **Can an AI agent help discover promising graphene-based mechanical energy-storage concepts while ensuring that every numerical performance claim is independently checked by physics?**

---

## Why SpiralAI?

Generative AI can produce creative scientific hypotheses, but plausible reasoning is not the same as physical validity.

SpiralAI separates **AI reasoning**, **physics calculation**, and **scientific verification**.

```text
Scientific Target
       ↓
Meta Muse Spark Open-1026
       ↓
Candidate Design
       ↓
Deterministic Python Physics
       ↓
Independent Scientific Verifier
       ↓
Verified Feedback
       ↓
Muse Redesigns
       ↓
Repeat or Stop
```

The AI is allowed to propose designs.

The AI is **not** allowed to approve its own numerical results.

---

## Current Agent Workflow

SpiralAI follows an iterative:

**propose → calculate → verify → redesign**

workflow.

For each iteration:

1. **Muse Spark Open** proposes a candidate.
2. The deterministic Python physics engine evaluates the candidate.
3. The independent verifier checks the evidence and model constraints.
4. Only the verified result is returned to the agent.
5. Muse uses that verified history to propose the next candidate.
6. The process stops when a justified stopping condition is reached.

## Example Verified Run

Example objective:

```text
Target system specific energy: 50 Wh/kg
```

A recent SpiralAI run produced:

| Iteration | Muse Proposal | Verified System Estimate | Verifier |
|---:|---:|---:|---|
| 1 | 5.0% strain | 26.07 Wh/kg | TARGET_NOT_REACHED |
| 2 | 7.0% strain | 49.61 Wh/kg | TARGET_NOT_REACHED |
| 3 | 7.1% strain | 50.96 Wh/kg | TARGET_REACHED |

The agent changed its candidate after receiving verified feedback and stopped when the independent verifier confirmed that the target had been reached **within the current theoretical screening model**.

### Important

**50.96 Wh/kg is not an experimentally demonstrated device result.**

It is a theoretical system-level screening estimate using explicit assumptions, including:

- idealized graphene mechanics;
- 30% active-material mass fraction;
- 60% recovery efficiency;
- published graphene material properties;
- no demonstrated physical device corresponding to this simulation.

## Independent Verification

Verification is deliberately isolated from the AI agent.

Current verifier outcomes include:

```text
TARGET_REACHED
TARGET_NOT_REACHED
PHYSICAL_CONSTRAINT_VIOLATION
MORE_VALIDATION_REQUIRED
INVALID_RESULT
```

For example, if Muse proposes a candidate outside the current conservative analytical screening boundary, SpiralAI can return:

```text
MORE_VALIDATION_REQUIRED
```

instead of presenting the high theoretical number as a successful design.

The verifier may recommend additional evidence such as:

- molecular dynamics;
- finite-element analysis;
- fatigue modelling;
- fabrication;
- mechanical cycling;
- experimental measurement.

---

## Evidence Provenance

Numerical performance values shown by SpiralAI must come from the deterministic physics layer.

For example:

```text
Result:
50.96 Wh/kg

Evidence type:
THEORETICAL_SIMULATION

Source:
Verified Python physics engine

Experimental validation:
NO
```

An attractive number generated by the language model is not accepted as scientific evidence.

## Meta AI Integration

SpiralAI uses the official hackathon version of Meta's open-weight model through Baseten:

```text
meta-models/muse-spark-open-1026
```

Muse Spark Open provides the agent's design reasoning.

It does **not** provide the authoritative numerical physics result.

The current separation is:

```text
Muse Spark Open
     │
     │ proposes
     ▼
Candidate
     │
     ▼
Python Physics Engine
     │
     │ calculates
     ▼
Independent Verifier
     │
     │ accepts / rejects / escalates
     ▼
Verified Evidence
     │
     ▼
Muse Spark Open
```

## Running SpiralAI

### 1. Install dependencies

```bash
python -m pip install openai pytest
```

### 2. Configure your inference key

SpiralAI expects:

```text
BASETEN_API_KEY
```

as an environment variable.

**Never place an API key directly in the source code or public repository.**

### 3. Run the iterative agent

```bash
python -m agent.iterative_agent
```

### 4. Run verification tests

```bash
python -m pytest -v
```
